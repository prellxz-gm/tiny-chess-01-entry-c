Hybrid 4 KB Python chess engine: a 9-entry opening book plus alpha-beta search with quiescence, transposition table, and MVV-LVA move ordering. Plays the strongest book move when the position is known, then searches.

## Run it

```sh
python3 main.py
```

The engine talks to the make.fun tiny-chess environment over `MAKEFUN_ENV_URL`.
